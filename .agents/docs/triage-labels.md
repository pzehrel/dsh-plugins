# 分类标签

工程技能使用以下五个角色；操作 GitHub 标签时采用对应名称。

| 角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待报告者补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交由代理独立实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

技能提及某个角色时，使用表中的 GitHub 标签。
调整词汇时修改此映射，并同步跟踪器中的标签。
