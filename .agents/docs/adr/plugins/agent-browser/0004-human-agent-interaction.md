# 普通浏览允许人机并行，敏感场景可人工接管

状态：已接受（本轮需求访谈修订后的 Q9）；实现尚未开始。

用户希望保留实测 Codex 中独立 Agent 指针、手动滚动无需切换模式的体验，因此不将明确交接设为所有浏览交互的前提。决定让 Agent 指针独立于用户系统鼠标，普通手动浏览不强制暂停 Agent；共享页面变化后必须重新确认目标，不能盲用过期坐标。

同时提供可选的人工接管状态：用户为登录等敏感场景显式暂停该页的 Agent 感知与操作，交回后重新观察再继续。它保护接管期间的后续采集与操作，但不能撤回已经交给模型的内容或逆转已完成的网站操作。

此选择优先保证低打扰的原生浏览体验，代价是必须处理共享滚动、焦点和表单状态的竞争；独立指针不意味着拥有两份彼此隔离的页面状态。用户对 Codex 的观察只用于说明需求动机，不作为其内部架构的证据。
