# 指针反馈与网页输入许可分开

状态：已接受（2026-10-20 本地浏览器体验补充访谈 Q1–Q5）。

参考 Codex 本地内置浏览器，将独立指针作为同一共享页面的可见反馈，按页面保存位置、按公开会话活动与页面可见性显示；它不移动系统鼠标，也不截获用户点击。选择允许纯视觉失败或到达等待超时后继续已获准的动作，避免后台或受限帧时钟使浏览器任务停滞；代价是指针展示本身不再构成输入可执行的保证。

输入许可仍来自同一页面控制边界。动画等待结束后重新核对审批许可、文档、完整目标绑定和命中；接管、取消、关页及目标失效不能被当成视觉降级。导航、实例替换和关闭撤销旧图形与帧；不能将旧动画完成视为新动作的授权。该决定细化 [ADR 0004](0004-human-agent-interaction.md)，不改变普通人工浏览无需强制交接或显式人工接管暂停感知与操作的规则。
