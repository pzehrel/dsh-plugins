# 仅面向官方 Desktop，保留原生共享页面

状态：已接受（本轮需求访谈 Q1、Q3、Q4、Q6，Q18–Q19 补充验收边界）；实现尚未开始。

为保留日常浏览的原生输入和人工接管体验，Agent 浏览器仅面向官方 DSH Desktop，用户与 Agent 操作同一个原生网页实例，不以后台 Chromium 的截图或实时画面流替代。允许通过插件替换浏览器实现、保留原入口及主要外观，无需继承原插件已经打开的页面，首次使用可以重新登录。

这放弃了画面流方案较容易覆盖 Web 的优势，也不再要求取得旧插件私有页面对象。首版先针对当前 macOS 官方 Desktop 验收，其他操作系统实际验证后再声明支持。保留原浏览器的入口、侧栏布局、标签页、地址栏和导航样式，只增加 Agent 指针、紧凑运行状态与暂停入口；审批复用 DSH 现有交互。

具体引擎接入见工程方案与测试边界已确认、尚待工程验证的[完整设计](../../../../../plugins/agent-browser/docs/design.md)，宿主缺口按 [ADR 0003](0003-upstream-browser-capabilities.md)处理，不能据此宣称纯插件已经能满足全部能力。

参见[需求记录](../../../../../plugins/agent-browser/README.md)和[能力调研](../../../../../plugins/agent-browser/docs/research.md)。
