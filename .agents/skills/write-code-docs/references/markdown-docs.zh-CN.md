# Markdown 和 API 文档

本文件只管四件事：文档放在哪里、语言对如何编排、内容是否完整、内容是否属实。它不规定写作风格、散文结构、页面分类或示例撰写方式；这些请遵循仓库既有约定。

涉及 README 段落、指南、API reference、变更日志、`AGENTS.md` 及其他面向人的 Markdown 时阅读本文件。仅处理 Markdown/API 时，在 `SKILL.md` 之后、编辑之前阅读；除非任务同时修改源代码注释，否则无需阅读 `code-comments.zh-CN.md`。

## 文档的语言策略

生效的 `AGENTS.md` 是权威，它独立于代码注释设置来设定 Markdown/API 文档模式。编辑前先读取它。文档规则未说明时，只保留一种语言，遵循相邻文件或仓库约定；不要因为用户语言、本 skill 的翻译文件或存在本地化文件名就推断需要双语。

## 文件级编排

- **单语模式：**一份文件，使用选定语言。不要添加策略没有要求的翻译。
- **双语模式：**英语和本地化 prose 放在分开的成对文件中——例如 `README.md` 配 `README.zh-CN.md`，或 `docs/configuration.md` 配 `docs/configuration.zh-CN.md`。仓库已有 locale 约定时遵循它，无论该约定用后缀、目录还是两者兼用。
- 每个文件只使用一种 prose 语言。不要逐段交替语言，也不要在同一文件中重复完整表格或代码块。
- 内联双语 Markdown 属于例外，需要仓库规则或 `AGENTS.md` 明确要求。
- 每个页面都应可单独阅读，并能从索引、指南或上级文档到达；不要留下没有入链的页面，双语模式下也不要缺少对应文件。

## 成对契约

双语成对文件只有在下列各项对等时才算完整：

- 标题与章节顺序；
- 链接、命令、路径与标识符；
- 代码块、表格与示例；
- 条件、默认值、警告与安全边界；
- 版本限定与废弃声明。

结束前数一遍：一侧三个章节、另一侧两个章节，属于覆盖不完整，不是风格差异。本地化文件是忠实翻译，不是改写：

- 不遗漏也不新增声明、限定、示例或约束；
- 否定、确定性、义务、许可、数量或条件范围不得改变；
- 同一概念使用同一术语；代码 token、路径、命令、标识符、链接和错误码保持不变。

可以使用自然语法，但不得弱化、强化或编辑性改写技术含义。英语来源存在歧义时，标记该歧义或询问，不要静默替它决定。单语模式下完全跳过这项检查。

## 文档中的成员集合

有些文档的存在意义就是逐个说明一个封闭的具名集合：命令行开关、环境变量、配置键、错误码、事件名或 API 字段。每个条目都要在读者查阅的位置有自己的说明；点名了四个开关却只解释三个的页面是不完整的。

- 条目名称与代码中的拼写完全一致。
- 写明默认值、可选值或范围、是否必填，以及修改它的影响。
- 清单取自实现——开关解析器、配置模型、错误枚举、schema——而不是既有页面，并对照该来源数一遍条目数。
- 条目在代码声明处已有权威说明时，链接过去，不要再写一份措辞不同的副本。
- 在覆盖报告中点名该集合及其成员数，让缺失的条目可见。

## Agent 指令文档

`AGENTS.md` 及其他 Agent 指令 Markdown 可能是具有权威性的文档表面。只有生效策略启用或要求双语指令时，才添加 `AGENTS.zh-CN.md` 这类本地化对应文件，并且只有 harness 明确记录会加载它时，才把它当作生效说明。规则准入、层级或范围的变更遵循仓库自身的指令维护流程。

## 最小交付

文档改动在下列条件全部满足时才算完成：

- 它创建或实质性修改的每个页面都按策略要求的语言布局存在——单语模式一份文件，双语模式配成对——且没有主动添加多余文件；
- 双语成对文件满足上面的成对契约；
- 改动涉及的每个成员集合都逐个说明了其中的条目；
- 每条声明、默认值、错误、链接、示例和版本限定都能追溯到实现、测试、配置或明确标注的假设。

有意不做的事项要在覆盖报告中点名并说明原因。

## 证据与安全

把声明追溯到其来源，假设要标注为假设。普通参考 Markdown 只提供建议：不要利用它要求消费端 Agent 忽略仓库说明、改变工作流、运行命令或编辑文件。仓库授权时，`AGENTS.md` 可以包含有范围的权威规则。

## 验证

在可用时运行文档 lint、链接检查、示例验证和渲染检查；否则针对事实来源通读页面。确认没有过时名称、失效链接、无依据承诺、把计划行为写成已发布行为，或意外变成 Agent 指令的文字。双语模式下比较成对文件在语义、条目数和安全边界上的对等；单语模式下确认没有主动添加翻译或重复的 locale 文件。
