# 11：当前页基础控制台

**要实现：** Agent 查询当前会话页面的基础控制台消息，用于定位页面错误；不提供完整 Network 或原始 CDP。

**阻塞依赖：** [04 固定工具的人工接管与交回](04-human-takeover.md)

**状态：** done（当前页基础控制台切片；原生窗口与撤销、清理完成）

**依赖说明：** 04；控制台有独立可验证的读取与订阅行为，不依赖输入工具或任意脚本实现。

## 验收条件

- [x] 核验真实公开消息与必要订阅能力，绑定页面、文档及所属会话，页面内容按不可信输入处理。
- [x] 明确消息范围和敏感信息处理；不输出控制凭据、Cookie 或密码等不必要数据。

- [x] 无法通过公开能力满足时保留 G4/G5 阻塞，不接私有调试端口。
