# 06：页面语义观察与有效元素引用

**要实现：** Agent 按需读取当前真实页面的文字与可交互元素，使用可验证的引用；不再限定计数测试字段。

**阻塞依赖：** [04 固定工具的人工接管与交回](04-human-takeover.md)

**状态：** done（主文档观察与引用切片；官方 Desktop 原生验收及清理完成）

**依赖说明：** 04；可用官方手动导航在单页验收，不以多标签工具为前提。

## 验收条件

- [x] 先验证公开读取能力与候选感知/定位库，固定实际选用版本并核对许可证；不默认引入完整浏览器服务。
- [x] 固定审查过的感知逻辑输出当前页面、文档及必要观察关联，过滤密码等敏感字段，不接受任意代码充当只读参数。
- [x] 导航、文档变化、滚动或重排后，受影响引用失效或重新定位；无法确定目标时明确返回冲突，不猜测。
- [x] 普通人工修改后读取真实新状态，接管期不能读取或留存观察，迟到结果不在交回后补发。
- [x] 受控边界与真实动态页面均验证；跨域 frame 留给 09，不宣称已支持。

受控回归覆盖非夹具页面、新文本、引用失效、接管迟到结果及同网址文档变化；公开方法与候选依赖版本/许可已核验。构建3d153edf9a36已在官方macOS Desktop 0.2.0-rc.2验证真实敏感字段过滤、人工新值、节点替换/重排/滚动/重载后的旧引用拒绝及接管屏障；卸载清理完成。受控迟到读取和VM克隆回归未冒充逐项原生竞态。完整G4/G5与首版仍未通过。见[观察实现与验证边界](../../../plugins/agent-browser/docs/semantic-observation-validation.md)。
