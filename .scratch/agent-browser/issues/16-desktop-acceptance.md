## 验收条件

- [ ] 真实模型自主选择并调用工具，人工修改后 Agent 读到同一状态、工具操作在同一页可见；不能仅使用 self-test 按钮作为最终证据。
- [ ] 组合验证接管、双向隔离、隐藏保活、上传、frame、控制台、脚本及网址恢复，特别检查新增通路能否绕过暂停和授权。
- [ ] 通过获准真实网站补充正常浏览和人工登录后的任务；验证码、风控由人处理，不用真实购买、删除或未经授权的信息提交验收。
- [ ] 构建、协议、当前 Host 与真实原生结果分级记录；保留版本、构建摘要、步骤、观察及未测项，不保存 Cookie、密码、控制凭据或无关会话内容。
- [ ] 运行统一门禁及实际需要的固定发布产物组合测试，写明执行与跳过数量；历史记录不升级成本次通过。
- [ ] 临时安装、测试页及资源按验证范围撤销；下载、完整调试、跨重启登录态明确为延期，不计为成功功能。
- [ ] 全部保留能力和门槛通过才声明首版完成；若不能满足，只报告具体阻塞，不修改既定范围、宿主或发布状态。

**主要覆盖：** G1–G5、A01–A17 全量复核；用户故事 1–44 的集成行为，重点补齐 44。

## 规格与实施边界

依据[首版实施规格](../../../plugins/agent-browser/docs/implementation-spec.md)、[领域词汇表](../../../plugins/agent-browser/GLOSSARY.md)及规格引用的 ADR。拆分已获确认；内容准备就绪不等于依赖已解除，也不表示本任务已开始或完成。

- 复用官方浏览器与统一页面控制边界，只补工具和必要交互；不修改 DSH 主程序、安装包或私有 IPC，不扩大自建浏览器。
- 权限来自真实 Agent 执行上下文及认证 Client 框架绑定，登录态共享不扩大页面权限。主验收边界是实际工具调用与同一可见共享页面结果。
- 固定测试页、替身测试和历史证据不代表完整产品通过。公开能力缺口保留为对应首版要求的阻塞，不擅自延期。
- 遵循仓库中文文档、ESLint、vitest 与统一门禁约定；记录实际版本、步骤、结果和未测项，不保存密码、Cookie 或控制凭据。
- 任务保存在本地，不自动发布远端事项、提交或推送代码。实际实施及宿主操作遵循用户的任务授权。
