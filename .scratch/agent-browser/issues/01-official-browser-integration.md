# 01：官方增强独立装配与固定同页工具

**要实现：** 用户从原浏览器入口打开独立增强，真实工具在固定自有页面读取、点击，再读取；不依赖另行加载旧实验插件。该切片是后续能力的最小可运行基础，不宣称完整浏览器交付。

**阻塞依赖：** 无（可先推进）

**状态：** done（固定自有页面切片）

**依赖说明：** 无。

## 验收条件

- [x] 核对匹配宿主的官方源码、发布产物、构建依赖与许可证，形成可复现的源码级增强；对应关系无法确认则记录 G1 缺口，不直接发布临时字符串补丁。

- [x] Host 使用真实工具执行身份，Client 只登记框架绑定的自有页面；沿用正式 Connection，与已有 Gateway 共存。
- [x] 同页 read/click/read 的页面、文档和可见计数一致；普通工具调用路径可用，人工标记轮询及 self-test 仅留在验证设施。
- [x] 关闭、卸载撤销固定工具目标和注册，builtin 可恢复；受控组合与真实 Desktop 都有证据，不把替身结果当原生通过。

## 实施结果

固定官方源码与 npm 产物已形成可复现的独立增强。22 个声明文件逐字节对应、七个关键函数规范化 AST 对应，MIT 许可证保留；源码补丁不修改主程序或官方发布 bundle。正常 `agent_browser` 工具、正式 Connection、关页及卸载均已验证，受控环境不加载旧实验插件。

最终 macOS 官方 Desktop `0.2.0-rc.2` 实测为同页同文档 `0 → 1 → 1`，原生点击可信；关页后拒绝旧目标，卸载后 builtin 恢复。测试站与驱动撤销，profile 四文件与主程序摘要不变。34 项回归及独立 Standards/Spec 审查通过。详见[独立装配验证](../../../plugins/agent-browser/docs/enhanced-assembly-validation.md)。

此完成状态只解除依赖本任务的基础装配阻塞。完整首版、模型自主调用、双真实会话及 A01/A02/A06/A08 的剩余矩阵继续由后续任务验证；本轮未提交、推送或发布远端事项。
