# 04：固定工具的人工接管与交回

**要实现：** 用户显式暂停该共享页的 Agent 感知与操作，确认屏障生效后手动修改页面；交回后工具重新观察。

**阻塞依赖：** [01 官方增强独立装配与固定同页工具](01-official-browser-integration.md)

**状态：** done（固定通路完成，不代表首版整体通过）

**依赖说明：** 01；固定页当前读写足以单独验证接管，不依赖后台保活或多标签工具完成。

## 验收条件

- [x] 复用页面控制边界与接管代次，阻止新读写，取消排队请求并阻断尚未交付和迟到结果。
- [x] 接管等待必要的在途结算；界面区分正在生效、已生效和失败，不能只切换按钮颜色。
- [x] 普通手动浏览不强制交接；交回不补发接管期采集、不重放旧请求。
- [x] 明确已经发送的内容及已经发生的副作用无法撤回；仅将当前固定通路标为通过。
- [x] 为后续观察、截图、输入、控制台及脚本接入同一暂停、取消和清理边界保留行为契约；每项新增能力仍须重新证明自身覆盖，不能继承成完整接管通过。
