# 03：隐藏保活、取消与关闭清理

**要实现：** 固定工具任务在侧栏收起或切换会话后继续且不抢焦点；明确关页、取消、断线或卸载时有准确结果，旧目标不会复活。

**阻塞依赖：** [01 官方增强独立装配与固定同页工具](01-official-browser-integration.md)

**状态：** done

**依赖说明：** 01 已完成；本任务已取得最终构建的官方 Desktop 同页保活、取消、关闭与卸载证据，以及统一控制边界回归。见[验证报告](../../../plugins/agent-browser/docs/page-lifecycle-validation.md)。

## 验收条件

- [x] 在官方增强中验证隐藏与关闭的真实生命周期，同一页面及文档在需要保活的场景保持不变，并提供紧凑后台状态。
- [x] 关页取消排队请求并撤销凭据，等待已开始清理和迟到登记撤销；重复清理幂等。
- [x] 断线或取消不附着到其他窗口的相同网址；在途原生动作可能生效时明确结果不明，不报告肯定未执行。
- [x] 请求具有唯一关联，重复或迟到结果不再次执行或交付；敏感动作结果不明时不能自动重试，后续动作复用此机制。
- [x] 使用延迟回调、关闭竞态、重复请求回归及真实隐藏/切会话/卸载验证。若保活无公开路径，G3 保持阻塞，不改用自建浏览器。

**主要覆盖：** G3；A08、A15；用户故事 29、30、41、42。

## 规格与实施边界

依据[首版实施规格](../../../plugins/agent-browser/docs/implementation-spec.md)、[领域词汇表](../../../plugins/agent-browser/GLOSSARY.md)及规格引用的 ADR。拆分已获确认；内容准备就绪不等于依赖已解除，也不表示本任务已开始或完成。

- 复用官方浏览器与统一页面控制边界，只补工具和必要交互；不修改 DSH 主程序、安装包或私有 IPC，不扩大自建浏览器。
- 权限来自真实 Agent 执行上下文及认证 Client 框架绑定，登录态共享不扩大页面权限。主验收边界是实际工具调用与同一可见共享页面结果。
- 固定测试页、替身测试和历史证据不代表完整产品通过。公开能力缺口保留为对应首版要求的阻塞，不擅自延期。
- 遵循仓库中文文档、ESLint、vitest 与统一门禁约定；记录实际版本、步骤、结果和未测项，不保存密码、Cookie 或控制凭据。
- 任务保存在本地，不自动发布远端事项、提交或推送代码。实际实施及宿主操作遵循用户的任务授权。
