# 08：受接管约束的页面截图

**要实现：** Agent 按需取得用户正在使用的共享页面截图，并得到正确页面、文档和结果关联。

**阻塞依赖：** [04 固定工具的人工接管与交回](04-human-takeover.md)

**状态：** done（共享页截图切片；正式附件及真实像素验收、清理完成）

**依赖说明：** 04；截图可从单页独立交付，不强制依赖语义快照工具完成。

## 验收条件

- [x] 在真实 guest 核验公开截图与附件输出能力，证明捕获的是同一可见实例，而非另一份同网址页面。
- [x] 核对敏感字段及截图的信息暴露行为，不能把 DOM 已过滤等同于截图已安全；不能保证的情形明确拒绝或报告限制，保留规格要求。
- [x] 接管期间不截图，不保留接管期缓存；导航、关闭或暂停后的迟到图片不交付。
- [x] 失败或能力缺失明确报告，不以后台浏览器、画面流或旧截图替代成功结果。

## 当前证据

受控通路已整合两阶段图片交付、Host 保存结算等待及 Client 私有文档代次；新增同文档导航组合回归。构建3d153edf9a36已在官方macOS Desktop 0.2.0-rc.2验证同页真实capturePage、正式image块、公开readImage、字节摘要和自有可见像素；敏感字段/frame拒绝及接管后拒绝已实测。真实保存延迟竞态没有原生重演，迟到截图拒绝引用受控回归；已保存附件不承诺删除。清理完成，完整G4/G5与首版仍未通过。见[验证报告](../../../plugins/agent-browser/docs/screenshot-validation.md)。

**主要覆盖：** G4 截图部分；A02、A05、A16；用户故事 10、11、19、20。
