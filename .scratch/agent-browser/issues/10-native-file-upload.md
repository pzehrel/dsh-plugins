## 验收条件

- [x] 先核验正式宿主文件选择、权限与上传路径，用自有临时文件和测试站验证，不以受限字节注入实验冒充完整原生上传。
- [x] 授权绑定具体文件、网站和当前页面，上传前复核；页面、文件或权限变化后重新授权或停止。
- [x] 取消、无权限、文件变化及目标变化结果明确；不能把选择文件当成上传成功，也不扩大为任意目录访问。
