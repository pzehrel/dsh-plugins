# 13：登录态范围配置与容器切换

**要实现：** 用户默认跨工作区共用本插件网站登录态，并可切换为工作区共享；新页面采用所选容器，已有页面维持原账号。

**阻塞依赖：** [02 跨工作区登录态可行性验证](02-login-scope-feasibility.md)、[05 本会话多标签页与导航](05-session-tabs-navigation.md)

**状态：** ready-for-agent

**所需结论：** 02=feasible

**依赖说明：** 02 的可行证据、05。02 必须提供全局共享的正面可行证据，仅完成调查或得到不支持结论不能解除本依赖。

## 验收条件

- [ ] 只采用 02 已证明的公开能力；提供最小配置入口，不重新设计浏览器界面。
- [ ] 全局容器与各工作区容器相互独立，切换不复制 Cookie、不删除旧容器、不改变已有页面账号。
- [ ] 在两个不同工作区及多个会话验证实际共享/隔离；共享账号不授予跨会话标签操作权限。
- [ ] 明确同一账号的退出登录等服务端状态可能相互影响，不能承诺账号共享同时隔离所有网站状态。
- [ ] 公开全局共享路径未成立时本任务阻塞，不自动默认工作区隔离，也不要求导出账号数据绕过。

**主要覆盖：** G2；A06、A07；用户故事 24–28。
