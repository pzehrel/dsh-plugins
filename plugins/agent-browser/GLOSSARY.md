# Agent 浏览器

本上下文讨论 DSH 内人与 Agent 共同使用的网页浏览能力。以下术语描述需求，不代表功能已经实现。

## 术语

**Agent 浏览器**：在 DSH 侧边栏内展示、允许用户和 Agent 感知及操作同一网页的浏览器。
避免：把独立后台浏览器的截图展示称为已完成的 Agent 浏览器。

**共享页面**：用户在侧边栏看到并可操作、同时供 Agent 读取和操作的同一个网页实例；相同网址的两个独立页面不属于共享页面。
避免：用“同一网址”代替“共享页面”。

**人工接管**：用户为登录等场景取得共享页面的独占操作权，期间该页的 Agent 感知与操作暂停；普通手动滚动不等于人工接管。
避免：把所有手动交互都称为人工接管，或把另开一个无法同步页面状态的浏览器窗口称为人工接管。

**Agent 指针**：共享页面内显示 Agent 指向或操作位置的标记，区别于用户的系统鼠标指针。
避免：把独立指针等同于独立的页面滚动、焦点或表单状态。

**标签页归属**：一个浏览器标签页所属的 DSH 会话；登录态共享不会自动改变标签页归属或授予其他会话操作权限。
避免：把账号共享等同于页面共享。

**登录态范围**：决定哪些 DSH 工作区共用网站登录状态的范围；全局共享覆盖不同工作区，工作区共享只覆盖同一工作区。
避免：把登录态共享等同于标签页操作权限共享。
