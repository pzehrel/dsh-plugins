# 固定工具的人工接管与交回

任务04已通过固定测试页 `read/click` 的受控回归与真实官方 macOS Desktop `0.2.0-rc.2` 验收。最终构建指纹为 `3b082962fd39`，Host 运行指纹与构建证据一致，最小结果见[白名单记录](evidence/human-takeover-verification.json)。复用官方标题内已有状态插槽，没有新增浏览器壳、导航或私有 IPC；通过范围不扩大为完整 G5/A05 或首版通过。

## 使用与确定性

普通手动浏览、修改或滚动不会自动接管。标题中的「人工接管」只作用于当前框架绑定的会话和标签页；按钮说明列明仅覆盖固定 `read/click`、无法撤回已经发送的内容或逆转已经发生的动作。

点击后先同步阻止新的本地采集与原生输入，中止旧接管代次的通信，再请求 Host 暂停。Host 立即拒绝新请求、取消待执行请求并撤销旧代次；旧结果及重复完成不交付。Client 等待所有已开始的命令、原生调用和当时在途轮询结算，期间只继续无网页内容的租约心跳。已开始的原生操作不能逆转，也不能仅用取消信号声称结束。

| 状态文案 | 实际含义 |
| --- | --- |
| 暂停正在生效，请稍候 | 本地已阻止新操作，但 Host 确认或必要在途结算尚未完成。 |
| 已接管，Agent 已暂停 | Host 已撤销旧代次，Client 已开始的固定通路操作均已结算。 |
| 接管失败，尚未确认暂停，请重试 | 屏障未完整确认，本地继续阻止采集，不能宣称安全接管；只允许显式重试。 |
| 正在交回 Agent | 仍保持本地屏障，等待 Host 确认，不执行旧请求。 |
| 交回失败，Agent 仍暂停 | 本地继续阻止感知与操作，不自动重试或交回。 |
| 工具就绪 | 当前固定通路可用；交回后还须由 Agent 发起新的 `read`，随后才允许 `click`。 |

点击「交回 Agent」仅在接管已完成或前次交回失败时有效。转换期间拒绝相反方向的交接，不将一次暂停承诺冒充交回成功。Host 交回后要求新的读取；直接点击返回「交回后须先重新读取当前页面」，迟到的旧读取不能解除屏障。不会自动补发接管期内容，也不会自动重放暂停前动作。

关闭、断线或卸载仍走[任务03的生命周期清理](page-lifecycle-validation.md)，并等待已经开始的交接 RPC；迟到确认不能把已关闭页改成可用或已接管。任务04实测构建使用协议4；当前标签导航、观察、截图及控制台整合登记为协议5，继续匹配 Host 与 Client 构建指纹。历史协议与证据仅代表当时构建，新增能力仍待各自证明屏障覆盖。

## 受控与真实 Desktop 验证

[统一控制边界测试](../test/human-takeover.test.ts)组合真实 Broker 与 Client，只替换正式 Connection 和原生 guest 外部服务。覆盖旧读取延迟结算、新请求拒绝、迟到结果丢弃、交回新观察门槛、失败保持停用、显式重试、mouseDown 在途接管不继续 mouseUp，以及关闭等待迟到交接确认。

真实 Desktop 经正式 `ToolRuntime.execute` 与真实 Agent 验证，没有发送模型消息：

| 场景 | 实际结果 |
| --- | --- |
| 初始读、原生点击、再读 | 计数为0、1、1，页面和文档身份一致；点击为可信原生事件。 |
| 后台读取中点击「人工接管」 | 共29项结果，前28项成功，末项为 `cancelled`，任务停止；标题稳定显示已接管。 |
| 接管期间修改输入 | 新 `read`、`click` 均因人工接管拒绝。 |
| 点击「交回 Agent」 | 直接点击先被重新读取门槛拒绝；新读取取得“接管期间人工修改 F2”，同一文档计数1；随后点击和读取计数均为2。 |
| 标题按钮输入 | 鼠标接管与交回均成功；正常 Tab 导航聚焦后 Space/Enter 也可交接，再读仍为2，没有重放旧点击。 |
| 关闭与卸载 | 旧页面身份拒绝，工具注销；临时监听器均关闭，四个 profile 文件字节一致，主程序 ASAR 摘要未变。 |

原生未稳定观察到「暂停正在生效」瞬态。延迟读取、mouseDown 与交接 RPC 的结算，以及失败保持停用和显式重试，仅由受控回归证明，不能写成原生故障注入通过。下载后的在途读取接管也有组合回归，确认暂停后不再追加采集或交付迟到下载结果。

构建 `111162514ca1` 曾因官方可拖动 Tab 捕获 pointer 导致鼠标接管失败，不计入通过证据。最终仅在按钮 `onPointerDown` 隔离传播，保留默认聚焦与鼠标、键盘 click，再以 `3b082962fd39` 复验。驱动的 `--lifecycle` 模式提供独立 `/read` 与 `/click`，不注册生产工具；复现入口沿用[生命周期复现](page-lifecycle-validation.md#复现)。证据文件经现有验收 CLI 读取时始终仅为 `recorded`，不会自动成为一次新的原生通过。

## 后续能力的接入契约

后续观察、截图、输入、控制台或脚本须使用同一页面凭据、请求代次、暂停许可、取消与清理边界；每个等待之后重新确认许可，交付前核对请求仍有效。订阅、缓存与 Agent 注入持续任务必须能够停止和等待结算，无法确认时只能显示等待或失败。

当前固定脚本不安装页面观察器、持久监听或后台任务，也不缓存已完成网页结果。任意脚本、截图、完整控制台及其他新通路尚未因此证明可暂停；尤其不能把脚本留下的持续任务当作网页自身活动而豁免。G5/A05 完整条件仍由新增能力和最终整体验收各自证明。
