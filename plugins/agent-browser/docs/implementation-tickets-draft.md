## 拆分原则与依赖

每项交付可独立展示或验证的行为，包含必要的 Host、Client、页面交互、结果和测试；不按“先全部后端，再全部界面”分层。工程事实未知的部分纳入对应行为的第一步验证，公开能力不足时保留该行为阻塞，不创建绕开宿主限制的实现任务。

目前未发现必须独立安排的大范围预重构；复用现有 Broker、正式 Connection 和官方页面适配所需的小调整随最早使用它的纵向任务完成。每项以一个新的实施上下文为粒度；若事实验证显露超出该粒度的必要改动，再提交具体拆分调整。

以下只列直接必要依赖，已传递的祖先不重复列出。任务编号表示依赖顺序，同一时刻可以存在多个可推进任务，不表示必须按编号串行执行。

1. **01 官方增强独立装配与固定同页工具**；依赖：无。交付可独立安装的正式增强最小切片，保留原浏览器并完成固定测试页读、点、再读。
2. **02 跨工作区登录态可行性验证**；依赖：无。交付真实公开能力结论，证明全局与工作区容器路径，或记录精确的 G2 阻塞。
3. **03 隐藏保活、取消与关闭清理**；依赖：01。交付切会话后台继续、关页停止及结果不明处理的完整生命周期。
4. **04 固定工具的人工接管与交回**；依赖：01。交付可生效、可失败、可交回的接管屏障，后续能力接入同一边界。
5. **05 本会话多标签页与导航**；依赖：03、04。交付本会话标签管理及导航工具，两会话双向隔离且隐藏页保活。
6. **06 页面语义观察与有效元素引用**；依赖：04。交付真实页面文字、可交互元素及敏感字段过滤，拒绝过期引用。
7. **07 原生页面操作、审批与 Agent 指针**；依赖：06。交付点击、填写、按键、滚动及敏感提交审批，结果可见且不移动系统鼠标。
8. **08 受接管约束的页面截图**；依赖：04。交付同一页面截图、信息暴露处理及迟到截图丢弃。
9. **09 跨域 frame 的观察与操作**；依赖：07。交付明确 frame 归属的感知与动作，跨源能力缺口保持阻塞。
10. **10 获准文件的原生上传**；依赖：07。交付指定文件、网站与页面绑定的上传闭环，正确处理取消及变化。
11. **11 当前页基础控制台**；依赖：04。交付页面范围内的控制台查询与订阅清理，接管期不采集留存。
12. **12 逐次审批的页面脚本**；依赖：07。交付目标和代码绑定的脚本执行，并管理其持续任务与接管清理。
13. **13 登录态范围配置与容器切换**；依赖：02 的可行证据、05。交付默认全局、可选工作区共享，旧页面不换号且权限不串页。
14. **14 重启后的网址与归属恢复**；依赖：13。交付正确会话和容器下的网址恢复，不重放操作或恢复表单。
15. **15 能力缺失与下载限制反馈**；依赖：01。交付准确的版本/能力提示及下载不支持结果，不绕过宿主限制。
16. **16 首版整体真实验收**；依赖：08、09、10、11、12、14、15。交付全部 G/A 条件及用户故事的当前版本证据；其余任务均由这些直接依赖传递覆盖。

初始拆分时可推进项为 01、02；任务02现已取得[正面可行证据](login-scope-validation.md)，固定页生命周期验证见[任务03报告](page-lifecycle-validation.md)，当前状态以任务索引为准。02 是工程事实验证：得到有证据的负面结论可以结束调查，但不等于 G2 通过；13 仍不能开始依赖未成立的实现，16 仍不能声明首版完成。其他能力同样不能把“已确认不支持”当成其保留用户故事已交付。

## 各任务的交付与验收

### 01 官方增强独立装配与固定同页工具

**依赖：** 无。

**交付：** 用户从原浏览器入口打开独立增强，真实工具在固定自有页面读取、点击，再读取；不依赖另行加载旧实验插件。该切片是后续能力的最小可运行基础，不宣称完整浏览器交付。

- 核对匹配宿主的官方源码、发布产物、构建依赖与许可证，形成可复现的源码级增强；对应关系无法确认则记录 G1 缺口，不直接发布临时字符串补丁。
- 保留官方界面、导航、主题、入口和快捷键；隔离模块、Sidebar、locale、样式及检查点身份，避免重复注册。
- Host 使用真实工具执行身份，Client 只登记框架绑定的自有页面；沿用正式 Connection，与已有 Gateway 共存。
- 同页 read/click/read 的页面、文档和可见计数一致；普通工具调用路径可用，人工标记轮询及 self-test 仅留在验证设施。
- 关闭、卸载撤销固定工具目标和注册，builtin 可恢复；受控组合与真实 Desktop 都有证据，不把替身结果当原生通过。

**主要覆盖：** G1；A01、A02、A06、A08 的基础部分；用户故事 1–6、42、44。

### 02 跨工作区登录态可行性验证

**依赖：** 无；复用既有固定版本调查与临时验证设施，不等待生产增强装配。

**交付：** 用自有测试站和两个不同工作区验证现有公开账号容器能力，给出 G2 的可行路径或可复查的阻塞结论。该任务不实现最终设置界面，也不预先承诺全局共享可行。

- 核对真实公开参数、版本及容器作用域；实际尝试跨工作区全局共享与工作区隔离，不能只根据同工作区进程分区推断。
- 只用自有测试标记验证存储，不访问真实账号，不导出 Cookie，不伪造工作区身份或访问私有接口。
- 如路径可行，提供可由 13 复用的公开契约及运行证据，验证不同容器、已有页面不变和会话权限独立。
- 如路径不可行，明确哪些现有公开能力不能满足要求、尝试范围及影响；G2、13 和整体发布继续阻塞，不能自动改为工作区默认或删除目标。
- 临时验证完成后撤销自身资源，保留必要的非敏感证据。

**主要覆盖：** G2 前置事实；A07；用户故事 24–28。

### 03 隐藏保活、取消与关闭清理

**依赖：** 01。

**交付：** 固定工具任务在侧栏收起或切换会话后继续且不抢焦点；明确关页、取消、断线或卸载时有准确结果，旧目标不会复活。

- 在官方增强中验证隐藏与关闭的真实生命周期，同一页面及文档在需要保活的场景保持不变，并提供紧凑后台状态。
- 关页取消排队请求并撤销凭据，等待已开始清理和迟到登记撤销；重复清理幂等。
- 断线或取消不附着到其他窗口的相同网址；在途原生动作可能生效时明确结果不明，不报告肯定未执行。
- 请求具有唯一关联，重复或迟到结果不再次执行或交付；敏感动作结果不明时不能自动重试，后续动作复用此机制。
- 使用延迟回调、关闭竞态、重复请求回归及真实隐藏/切会话/卸载验证。若保活无公开路径，G3 保持阻塞，不改用自建浏览器。

**主要覆盖：** G3；A08、A15；用户故事 29、30、41、42。

### 04 固定工具的人工接管与交回

**依赖：** 01；固定页当前读写足以单独验证接管，不依赖后台保活或多标签工具完成。

**交付：** 用户显式暂停该共享页的 Agent 感知与操作，确认屏障生效后手动修改页面；交回后工具重新观察。

- 复用页面控制边界与接管代次，阻止新读写，取消排队请求并阻断尚未交付和迟到结果。
- 接管等待必要的在途结算；界面区分正在生效、已生效和失败，不能只切换按钮颜色。
- 普通手动浏览不强制交接；交回不补发接管期采集、不重放旧请求。
- 明确已经发送的内容及已经发生的副作用无法撤回；仅将当前固定通路标为通过。
- 为后续观察、截图、输入、控制台及脚本接入同一暂停、取消和清理边界保留行为契约；每项新增能力仍须重新证明自身覆盖，不能继承成完整接管通过。

**主要覆盖：** G5 基础；A05；用户故事 17–22。

### 05 本会话多标签页与导航

**依赖：** 03、04；需要隐藏页继续存活，并保证导航同样服从人工接管。

**交付：** Agent 列出、创建、选择、关闭本会话标签页，并在同一共享页导航、刷新、前进后退；用户仍使用官方标签和导航界面。

- 页面归属来自实际 Agent 与框架上下文；模型不能指定会话、工作区或 guest 身份取得权限。
- 两个真实会话分别正反向验证越权拒绝；伪造、关闭、重建和其他窗口目标不误绑定。
- 导航、页面重建及文档切换使旧观察和请求失效；相同网址不代表同一页面。
- 创建或切换标签不抢其他会话焦点；关闭按 03 撤销，接管按 04 拒绝导航，后台状态准确。
- Agent 工具结果和侧栏的实际地址、标签及页面身份一致。

**主要覆盖：** A01、A06、A08、A11 的跨站导航部分；用户故事 7、8、12、23、28–30。

### 06 页面语义观察与有效元素引用

**依赖：** 04；可用官方手动导航在单页验收，不以多标签工具为前提。

**交付：** Agent 按需读取当前真实页面的文字与可交互元素，使用可验证的引用；不再限定计数测试字段。

- 先验证公开读取能力与候选感知/定位库，固定实际选用版本并核对许可证；不默认引入完整浏览器服务。
- 固定审查过的感知逻辑输出当前页面、文档及必要观察关联，过滤密码等敏感字段，不接受任意代码充当只读参数。
- 导航、文档变化、滚动或重排后，受影响引用失效或重新定位；无法确定目标时明确返回冲突，不猜测。
- 普通人工修改后读取真实新状态，接管期不能读取或留存观察，迟到结果不在交回后补发。
- 受控边界与真实动态页面均验证；跨域 frame 留给 09，不宣称已支持。

**主要覆盖：** G4 观察部分；A02、A04、A05；用户故事 9、11、14。

### 07 原生页面操作、审批与 Agent 指针

**依赖：** 06；复用其当前文档、元素引用和目标核验，不要求先完成跨域 frame 或多标签工具。

**交付：** Agent 在当前共享页点击、填写、按键和滚动，用户看到独立 Agent 指针及操作结果；敏感动作经宿主审批。

- 核验公开原生输入能力，支持普通动态表单；执行前复核目标、可见性、命中和当前文档，Agent 写操作串行。
- Agent 指针不移动系统鼠标；普通手动滚动不强制暂停，但受影响目标重新定位。
- 提交信息、发送、购买、删除等敏感动作及无法可靠确认风险的动作先审批；审批不可用或拒绝时不执行。
- 审批绑定页面、网站、文档、动作及内容，实际执行前再次核验，目标变化使旧批准失效；网页声称已授权无效。
- 使用可控测试站验证普通填写、模拟敏感提交、拒绝、布局竞态及结果不明，不用真实购买或删除验收；中文输入法与复制粘贴在真实 Desktop 验证。
- 接管覆盖新增输入通路，取消和超时不自动重试可能已生效的敏感动作。

**主要覆盖：** G4 输入部分、G5 审批部分；A02–A05、A10、A15；用户故事 13、14、16、17、33、34、41。

### 08 受接管约束的页面截图

**依赖：** 04；截图可从单页独立交付，不强制依赖语义快照工具完成。

**交付：** Agent 按需取得用户正在使用的共享页面截图，并得到正确页面、文档和结果关联。

- 在真实 guest 核验公开截图与附件输出能力，证明捕获的是同一可见实例，而非另一份同网址页面。
- 核对敏感字段及截图的信息暴露行为，不能把 DOM 已过滤等同于截图已安全；不能保证的情形明确拒绝或报告限制，保留规格要求。
- 接管期间不截图，不保留接管期缓存；导航、关闭或暂停后的迟到图片不交付。
- 失败或能力缺失明确报告，不以后台浏览器、画面流或旧截图替代成功结果。

**主要覆盖：** G4 截图部分；A02、A05、A16；用户故事 10、11、19、20。

### 09 跨域 frame 的观察与操作

**依赖：** 07；已传递依赖 06 的观察与引用，以及 04 的接管。

**交付：** 在同一共享页面内，对所需跨域 frame 正确观察、定位及执行原生操作，结果保持文档和 frame 归属。

- 先以自有跨源测试站验证正式公开方法，不绕过宿主隔离或调用私有调试接口。
- frame 导航、替换及布局变化后，旧引用与坐标失效或重新定位；审批仍绑定实际网站、文档和动作。
- frame 的观察、动作及结果同样服从接管和关闭，不因嵌套页面扩大到其他会话。
- 无公开实现路径时明确记录 G4/A11 阻塞，不能以“返回不支持”将这项保留能力标为已交付，也不能把读取不到当空白成功。

**主要覆盖：** G4 frame 部分；A04、A05、A11；用户故事 14、15、34。

### 10 获准文件的原生上传

**依赖：** 07；复用具体动作与目标绑定的正式审批及原生操作，不要求先完成跨域 frame。

**交付：** 用户核对具体文件与网站后，Agent 在当前页完成原生上传，并获得可核验结果。

- 先核验正式宿主文件选择、权限与上传路径，用自有临时文件和测试站验证，不以受限字节注入实验冒充完整原生上传。
- 授权绑定具体文件、网站和当前页面，上传前复核；页面、文件或权限变化后重新授权或停止。
- 取消、无权限、文件变化及目标变化结果明确；不能把选择文件当成上传成功，也不扩大为任意目录访问。
- 接管、关页及取消同样阻止后续上传动作；已发出结果不明时不自动重复提交。
- 公开能力缺失时 G4/A12 保持阻塞，上传不因下载延期而自动延期。

**主要覆盖：** G4 上传部分、G5；A10、A12、A15；用户故事 35、36。

### 11 当前页基础控制台

**依赖：** 04；控制台有独立可验证的读取与订阅行为，不依赖输入工具或任意脚本实现。

**交付：** Agent 查询当前会话页面的基础控制台消息，用于定位页面错误；不提供完整 Network 或原始 CDP。

- 核验真实公开消息与必要订阅能力，绑定页面、文档及所属会话，页面内容按不可信输入处理。
- 明确消息范围和敏感信息处理；不输出控制凭据、Cookie 或密码等不必要数据。
- 接管时停止面向 Agent 的订阅和缓存，不采集留存接管期消息；交回从新观察开始，不补发暂停期数据。
- 导航、关页、卸载及在途取消正确撤销订阅，其他页面消息不能混入。
- 无法通过公开能力满足时保留 G4/G5 阻塞，不接私有调试端口。

**主要覆盖：** G4 控制台部分、G5；A05、A14；用户故事 19、20、38、40。

### 12 逐次审批的页面脚本

**依赖：** 07；复用正式审批与当前文档目标绑定，不强制依赖基础控制台工具。

**交付：** 用户逐次核对目标和代码后，Agent 在本会话共享页面执行获批脚本，结果及持续任务受统一控制。

- 首先验证公开执行范围以及脚本创建的 Agent 任务能否识别、停止和清理；不能保证时保留 G4/G5 阻塞，不宣传完整隐私暂停。
- 每次审批绑定页面、文档、网站和确切代码；审批期间变化使旧批准失效，批准脚本不自动批准后续敏感动作。
- 不授予宿主 Node、DSH 主界面、其他会话或无限调试能力；普通观察工具不能变成无审批脚本入口。
- 接管阻断新执行和未交付结果，清理 Agent 注入的观察器、定时任务等持续活动；无法确认停止时不显示接管成功。
- 关页、卸载、取消及超时有明确结果，已发生的网站副作用不承诺回滚，敏感脚本结果不明不自动重试。

**主要覆盖：** G4 脚本部分、G5；A05、A10、A14、A15；用户故事 19–22、39–41。

### 13 登录态范围配置与容器切换

**依赖：** 02 的可行证据、05。02 的调查完成状态不能代替其可行证据。

**交付：** 用户默认跨工作区共用本插件网站登录态，并可切换为工作区共享；新页面采用所选容器，已有页面维持原账号。

- 只采用 02 已证明的公开能力；提供最小配置入口，不重新设计浏览器界面。
- 全局容器与各工作区容器相互独立，切换不复制 Cookie、不删除旧容器、不改变已有页面账号。
- 在两个不同工作区及多个会话验证实际共享/隔离；共享账号不授予跨会话标签操作权限。
- 明确同一账号的退出登录等服务端状态可能相互影响，不能承诺账号共享同时隔离所有网站状态。
- 公开全局共享路径未成立时本任务阻塞，不自动默认工作区隔离，也不要求导出账号数据绕过。

**主要覆盖：** G2；A06、A07；用户故事 24–28。

### 14 重启后的网址与归属恢复

**依赖：** 13；恢复必须验证正确账号容器关联，而不仅是记住一串 URL。

**交付：** 重开 DSH 后，用户在正确会话和容器中恢复标签页网址，按需重新登录；任务不会自动重复执行。

- 沿用官方网址恢复逻辑和独立增强检查点，不迁移 builtin 已有页面或账号数据。
- 实际重启后核对会话、网址、登录态范围及容器关联，不用受控 store 测试替代重启结果。
- 不恢复未提交表单，不重放旧请求、输入或提交；首版不承诺登录态跨重启持久化。
- 过期页面、观察和审批不能在新实例中复用，恢复后的 Agent 先重新观察。

**主要覆盖：** A04、A09；用户故事 31、32。

### 15 能力缺失与下载限制反馈

**依赖：** 01；使用最小正式增强即可独立验证版本及不支持行为。

**交付：** 用户和 Agent 得到准确的版本/能力限制；遇到网页下载时明确停止该步骤，不报告生成了文件。

- 已验证能力按实际版本启用；缺失公开能力、平台或版本不匹配明确说明，不用历史证据冒充当前可用。
- 在自有下载测试站验证 Agent 与人工路径受当前宿主限制，不通过私有接口、Host 匿名请求或另开浏览器绕过。
- 下载不支持是已接受首版行为；完整 Network、断点、原始 CDP 和跨重启登录态也不显示为已支持。
- 全局共享、上传、frame 等保留能力的缺失仍阻塞对应交付，不能借统一“不支持”提示把它们自动改成首版可选项。
- 界面说明限于帮助用户判断下一步，不把内部协议和调试细节塞进浏览流程。

**主要覆盖：** A13、A16；用户故事 37、43。
