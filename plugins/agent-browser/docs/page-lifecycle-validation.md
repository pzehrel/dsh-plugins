# 隐藏保活、取消与关闭清理验证

任务03已完成固定自有页面的生命周期切片。官方公开保活路径可用，G3 在此切片内通过；完整首版及后续能力仍须各自验收。复用官方浏览器和统一控制边界，没有扩展自建浏览器。

## 生命周期约定

官方 `keepMounted` 与 Session view 保留机制负责隐藏和切会话保活。工具层跟随正式 occurrence 信号，隐藏不撤销目标；明确关闭、卸载、连接失效才停止。标签标题显示「工具就绪」「Agent 执行中」「结果不明，请核对」「连接已断开，请重新打开」或「工具已停止」，不展示网页内容或控制凭据，不抢焦点。

命令串行执行；独立轮询每250毫秒续租，在途只续租而不领取下一条命令。Host 租约为5秒，控制请求超时为15秒，单次 Client RPC 最长等待3秒。失联或登记回复丢失时，Host 租约兜底撤销旧目标。公开 Connection 状态或代次改变会立即停止本地操作；连接恢复不搜索相同网址、不自动重绑或重放，用户须重新打开标签页。

关闭先中止本地信号、停止轮询并请求撤销 Host 登记，然后等待迟到登记、已开始通信及原生操作结算。输入许可返回后核对文档，再同步核对页面实例与生命周期，避免文档检查后又等待许可。关闭发生在 mouseDown 等待期间时，不再发送 mouseUp。点击后的读取必须仍属定位时的文档；同网址重载不能接收旧坐标或冒充原点击结果。正在执行的原生方法无法逆转；清理会等待其结算，不能因此宣称已发生的动作未执行。

## 结果与去重

正式工具调用的 `exec.callId` 与真实会话组成关联，生命周期内重复调用直接拒绝，不再执行或补发旧观察。仅记录关联身份，不保存已完成网页观察缓存。

| 错误标识 | 含义 |
| --- | --- |
| `cancelled` | 调用被取消。 |
| `timeout` | 等待超过15秒。 |
| `closed` | 页面已关闭或目标不存在。 |
| `unloaded` | 插件卸载，拒绝新登记和等待请求。 |
| `disconnected` | 连接中断或租约过期。 |
| `unknown` | 已交付给 Client 的点击可能生效；阻止后续请求，不自动重试。 |
| `duplicate` | 已处理同一真实会话的调用关联，不重放。 |

`not-started` 表示未发出；`not-delivered` 表示读取可能完成但结果不交付；`unknown` 不保证点击未发生。已发出点击的取消、超时、关闭或断线均保守报告 `unknown`，错误说明保留原始停止原因。迟到与重复完成不会交付给其他请求。

## 构建身份与实测分层

本轮第一次原生测试中，新 Client 的后台读取可以继续，但取消及重复关联仍返回旧 Host 的行为。这次结果不作为新控制层通过。已观察到同名本地包重装后运行版本未跟随安装产物更新，具体缓存层尚未定位；不把磁盘摘要单独视为运行版本证明。

独立安装包采用 `dsh-plugin-agent-browser-<构建指纹>`，逻辑 Sidebar、工具及路由身份保持固定，安装前先卸载旧增强。Host 健康检查与登记回复携带构建指纹，任务03构建的 Client 同时校验协议3与自身指纹，不匹配即撤销登记并停止。构建指纹覆盖固定源码、补丁、工具与构建器；运行值须与 `build-evidence.json` 相同。本文记录的指纹不包含凭据。

受控回归覆盖取消确定性、失联租约、在途续租、超时、重复和迟到完成、停止后的登记、关闭等待原生操作、点击中途关闭、Connection 状态失效及构建不匹配拒绝。源码增强组合回归运行构建后的真实 Host 与 Client，而非只测试源码替身；外部 store、宿主服务和原生 guest 仍为替身，不代表 Desktop 成功。

## 最终真实 Desktop 结果

环境为 macOS 官方 Desktop `0.2.0-rc.2`。最终安装包为 `dsh-plugin-agent-browser-29f071b4adb1`；运行 Host 返回 `29f071b4adb1`，与构建证据一致，Client 同时通过登记握手。真实 `ToolRuntime.execute` 使用指定真实 Agent；未发送模型消息，也未访问真实账号。

人工输入「生命周期最终验收 D」后，read/click/read 返回同一页面和文档，计数为 `0、1、1`，原生点击后 `lastTrusted=true`。启动80次有界读取，标题显示「Agent 执行中」；收起侧栏时已完成34次，切到空白草稿时已完成74次，最终80次全部成功且文档不变。运行与结束后仍停留在草稿，没有抢回会话焦点。

另一轮后台读取被取消后停止，重复最近成功调用的关联明确返回 `duplicate`，没有再次点击。取消时驱动的合成信号先于结果交付中止，因此这条原生记录只证明停止；具体 `cancelled`、`unknown` 与未交付分类由 Broker 回归证明。新的明确 read/click/read 随后成功，计数为 `1、2、2`；回到原页可见计数2和人工内容，文档仍相同。

运行中关页让后台读取返回 `closed`，旧目标再次调用同样被拒绝。重新打开同网址取得新的 `pageId` 和文档身份，正常工具闭环成功。再次运行后台读取并卸载增强，等待请求返回 `unloaded`，正式工具注销，增强测试站端口关闭。builtin 回退页能重新加载原有自有测试站；本轮测试标签页随后关闭，原实验页保留。

临时增强与驱动已从官方管理器卸载。四个 profile 文件与最初基线逐字节一致，驱动与增强服务端口均拒绝连接，主程序 ASAR 摘要未变。最终 `pnpm check` 的 ESLint、类型检查与45项测试通过，9个测试文件，无跳过；历史发布包回归使用既有实验目录启用。shell 为 Node 22.20.0，项目要求24.21.0，存在引擎警告，不能据此增加 Node 22 支持。

Standards 与 Spec 独立审查发现并修复了输入文档竞态、点击后文档归属及一次性驱动卸载等待缺口；复审无未解决发现。机器证据见[生命周期验证记录](evidence/page-lifecycle-verification.json)。

## 复现

```sh
pnpm --filter ./plugins/agent-browser run build
node tools/prepare-enhanced-native-probe.ts session-实际验收身份 --lifecycle
```

先从官方管理器安装增强，再安装脚本返回的一次性驱动。`control.json` 保存只用于回环验证的临时 Bearer 凭据，不进入仓库。`GET /status` 的 `hostBuild` 必须与当前构建指纹相同，然后才运行工具。

驱动保留 `/run`、`/closed`；可选 `--lifecycle` 额外开启六个验证操作：`POST /start` 启动最多80次同一固定页读取，`GET /job` 查看白名单结果，`POST /cancel` 取消当前任务，`POST /repeat` 重复最近成功调用的关联并要求拒绝；`POST /read`、`POST /click` 使用新的调用关联，仅针对最近确认的页面执行一次固定动作，用于接管与交回验证。尚无成功目标时拒绝，不自动选取其他页面。`GET /status` 同时核对工具、固定测试网址和运行构建。它们只在验证设施，不注册生产工具或页面实现，不发送模型消息。

驱动全部 HTTP 请求和后台循环共享卸载信号；卸载先取消、停止监听，再等待所有在途处理结算。真实 HTTP 回归证明普通 `/run` 的迟到读取不能在卸载后继续点击。

后续能力验证可显式追加 `--actions=observe,resolve,screenshot`，开启 `POST /call`，JSON 正文即正式工具参数。只有本次配置列出的动作可调用；正文最多32 KiB，仅接受动作、页面、引用、地址及有限动作数据字段，不接受工具名称、会话、工作区或控制凭据。驱动始终使用配置的真实 Agent 与 `agent_browser`，每次生成新调用关联；结果来自正式工具流水线，不表示模型自主调用。未配置时路由关闭；参数不符返回400，超限返回413。此入口仅用于获准自有测试页，不能用作通用远程控制服务。断开单次请求会中止对应信号，卸载仍等待已开始操作结算。

在自有页面人工修改后运行初次闭环，再启动后台任务并收起侧栏、切换到空白草稿；核对页面和文档不变且不抢回焦点。随后验证取消、旧关联、在途关页、重新打开与卸载。完成后卸载两个临时插件、关闭测试标签页，比较 profile 基线、端口及主程序摘要。全局物理连接断开会影响其他工作，本轮只在公开 Connection 边界注入断线，真实 Desktop 恢复使用关页、重新打开和卸载，不声称整个应用网络断开已实测。

本切片不表示完整人工接管、任意网页工具、多标签操作、截图、上传或首版整体已完成。
